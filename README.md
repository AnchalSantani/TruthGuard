# TruthGuard

AI-Powered Fake News Detection Platform built using Flask, Machine Learning, OCR, and SQLite.

## Features

- Single News Verification
- Bulk News Analysis
- Image OCR Verification
- File Upload Analysis
- AI Chatbot Assistance
- Prediction History Storage
- Machine Learning Model (Logistic Regression)
- TF-IDF Vectorization

## Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Flask
- Python

### Machine Learning
- Scikit-Learn
- Logistic Regression
- TF-IDF Vectorizer

### Database
- SQLite

### OCR
- EasyOCR
- OpenCV

## Installation

```bash
git clone https://github.com/AnchalSantani/TruthGuard.git
cd TruthGuard

python -m venv .venv
.venv\Scripts\activate

pip install -r requirements.txt

python app.py
```
